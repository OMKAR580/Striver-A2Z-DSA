## 🔌 Chrome Extension Auto-Sync System

This project includes a custom Chrome Extension + Local Sync Server that automatically detects your accepted submissions on **TakeUForward (Striver's A2Z Sheet)**, **LeetCode**, **GeeksforGeeks**, and **Coding Ninjas (Code360)**.

### 🌟 How It Works:
1. When you solve a problem on TakeUForward/LeetCode and get **"Accepted"**, a glassmorphism modal pops up on the screen.
2. It auto-detects the question title, programming language, code snippet, and target folder (e.g. `01_Learn_Basics/patterns`, `03_Arrays/easy`).
3. Upon clicking **🚀 Save & Push to GitHub**, it automatically:
   - Saves the code locally into `D:\Stirver_A2Z_DSA\<folder>\<filename>` with problem metadata headers.
   - Pushes the code directly to your GitHub Repository (`OMKAR580/Striver-A2Z-DSA`).

### 🛠️ Setup Instructions:
1. **Start Sync Server**:
   Double click `start_sync_server.bat` in the project root directory (runs on `http://localhost:3456`).
2. **Install Chrome Extension**:
   - Open Google Chrome and go to `chrome://extensions`.
   - Enable **Developer mode** (top right toggle).
   - Click **Load unpacked** (top left).
   - Select the `chrome_extension` folder inside `D:\Stirver_A2Z_DSA\chrome_extension`.
3. **Start Solving!**
   - Go to Striver's sheet / TakeUForward / LeetCode, solve questions, and watch your local project & GitHub stay 100% in sync automatically! 🎉
